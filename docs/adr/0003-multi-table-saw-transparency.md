# Multi-Table SAW Calculation Transparency

Halaman hasil perangkingan menyajikan transparansi perhitungan SAW secara penuh melalui empat tabel berurutan: Matriks Keputusan ($X_{ij}$), Matriks Ternormalisasi ($R_{ij}$), Matriks Terbobot ($W_j \times R_{ij}$), dan Tabel Perangkingan Akhir ($V_i$), disertai fitur ekspor CSV. Keputusan ini diambil karena transparansi matematis merupakan syarat utama validasi skripsi untuk membuktikan kesesuaian hasil sistem terhadap perhitungan manual spreadsheet di hadapan dosen penguji.
